A few realistic options, roughly ordered by impact:                            
                                                                               
  - xG over/underperformance — rolling (goals - xG) tells you if a team is     
  finishing above expectation (likely to regress) or below (may be better than
  results show). Computable from data we already have.

  Medium impact
  - Rest days — days since last match for each team. Easy to compute from
  existing dates. A team on 3 days rest vs 7 days rest is meaningful, especially
  late season.
  - Head-to-head record — some fixtures have consistent patterns regardless of
  form (e.g. certain promoted sides always lose to big 6). Computable from
  existing data.

  Lower impact / harder to get
  - Season stage — match week as a feature. Captures early-season
  unpredictability vs. late-season pressure games.
  - Promoted team flag — patches the ELO cold-start problem for newly promoted
  sides.
  - Manager changes — short-term bounce after a new manager is real but hard to
  source historically.

  Betting odds would likely push accuracy the most. Want to try that, or one of
  the computable ones first?
